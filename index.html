Help & Support

Everything you need to know about GAK AI

What is Groq?

Groq provides ultra-fast AI inference using revolutionary LPU (Language Processing Unit) architecture, offering free high-speed access to models like Llama 3.3 and DeepSeek R1.

How to get an API Key?

Visit console.groq.com, create a free account, and generate an API key starting with gsk_.

Is my API key safe?

Yes! Your API key is stored exclusively in your browser's local storage and is sent directly to Groq's official API endpoint. It is never logged or shared.
